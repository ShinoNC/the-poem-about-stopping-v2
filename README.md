# The Poem About Stopping — v2

An entry for make.fun's bounty **"The poem about stopping"** ($35, top 20 paid, 1-hour window).
Revision of the v1 entry, rebuilt from the v1 judge feedback: v1 was judged
thin — one gesture, an ending that settled rather than turned. This version
stacks four exact images (a key turned halfway, a humming hallway light, a
cooling kettle, a coat sleeve reaching for the dark) and ends with a turn:
stopping reframed as keeping the evening.

`main.ts` writes one short poem (211 characters) to `/output/entry.txt`.

## Run

```sh
node main.ts   # writes /output/entry.txt (deterministic, no network)
```
